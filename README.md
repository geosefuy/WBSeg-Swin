# WBSeg-Swin

WBSeg-Swin is an effective segmentation model that pinpoints exact areas and the severity of metastases through pixel masks. It can be a practical tool for physicians to undergo initial diagnosis, making the screening of cancer patients more efficient.

It uses Swin Transformer model to focus on multi-view segmentation of bone metastases, along with a feature fusion model.
